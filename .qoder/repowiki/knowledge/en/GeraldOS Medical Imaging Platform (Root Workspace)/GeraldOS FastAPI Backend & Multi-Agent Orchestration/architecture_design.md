The module is a layered FastAPI application under `app/`. `main.py` is the single entry point that mounts all domain routes (patients, appointments, clinical workflow, equipment, inventory, reports, analytics) and an Orthanc PACS proxy; each route uses raw SQL via `sqlalchemy.text` against schema-scoped tables (`patient.*`, `scheduling.*`, `workflow.*`, `equipment.*`, `inventory.*`, `reporting.*`). Database access is centralized in `db/session.py`, which exposes a SQLAlchemy engine and a `get_db()` dependency injector. Configuration lives in `core/config.py` as a Pydantic `BaseSettings` class loaded from `.env`, providing DATABASE_URL, REDIS_URL, MINIO, KEYCLOAK, ORTHANC, FHIR and GEMINI keys. External integrations (Keycloak JWT verification, FHIR resource creation, n8n webhooks, MinIO object storage) are encapsulated in `core/integrations.StackIntegrationManager`. The `agents/orchestration.py` file defines a LangGraph `StateGraph` with typed `AgentState` and independent agent nodes (reception, scheduling, equipment, inventory, executive, workflow_super) wired through a router node to form a compiled `langgraph_app` used to drive cross-domain operations. The Dockerfile builds a `python:3.11-slim` image running uvicorn on port 8000, with `requirements.txt` pinning the full stack.
