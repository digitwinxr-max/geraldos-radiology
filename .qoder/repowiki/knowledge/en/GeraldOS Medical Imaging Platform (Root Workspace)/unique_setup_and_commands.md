`docker compose up` starts the entire approved stack (Postgres, Redis, MinIO, Orthanc, Keycloak, HAPI FHIR, Dicoogle, n8n, OHIF, LangGraph); `npm run dev` launches the Next.js frontend which proxies API calls to the backend; `npm run db:push` applies the Drizzle schema to the Postgres container; `npm test` runs the Vitest suite covering AI review, decision engine, events, and reporting helpers.
