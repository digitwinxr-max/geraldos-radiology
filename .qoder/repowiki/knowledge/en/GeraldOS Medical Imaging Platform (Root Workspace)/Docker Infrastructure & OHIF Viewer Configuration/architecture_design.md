This leaf module ships declarative configuration artifacts consumed by Docker Compose or container orchestration; it contains no executable code. Under `docker/`, three subdirectories each configure a distinct backend service: `orthanc/orthanc.json` sets the Orthanc PACS (storage/index directories, DICOM port 4242, HTTP API on 8042, DicomWeb endpoints at `/dicom-web/` and `/wado`, PostgreSQL plugin loading, and disables auth for local dev); `dicoogle/dicoogle.properties` configures a secondary DICOM indexer/storage using Lucene index and file storage on ports 104 (DICOM) and 8081 (web); `postgres/init-schemas.sql` bootstraps eight domain-scoped schemas (`auth`, `patient`, `scheduling`, `workflow`, `equipment`, `inventory`, `reporting`, `analytics`) with their tables, including state-tracking and KPI structures. The `ohif-config/app-config.js` is the client-side entry that wires the OHIF viewer to GeraldOS via a same-origin proxy at `/api/orthanc/dicom-web`, routing QIDO-RS/WADO-RS/STOW-RS through the proxy so credentials never reach the browser. Dependency direction is one-way: the OHIF config points outward to the Orthanc service exposed by the docker configs; there are no cross-references between the three docker subdirectories.
