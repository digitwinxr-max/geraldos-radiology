PostgreSQL must be initialized with `docker/postgres/init-schemas.sql` before any GeraldOS services start, since each domain schema and table is created idempotently via `CREATE SCHEMA IF NOT EXISTS` / `CREATE TABLE IF NOT EXISTS`. Orthanc expects its PostgreSQL plugin binaries (`libOrthancPostgreSQLIndex.so`, `libOrthancPostgreSQLStorage.so`) mounted under `/usr/share/orthanc/plugins/` inside the container.
