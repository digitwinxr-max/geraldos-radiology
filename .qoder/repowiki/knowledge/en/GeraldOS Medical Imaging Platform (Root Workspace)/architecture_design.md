The root orchestrates four child layers through shared configuration and environment: `package.json` declares the unified toolchain (Next.js, Drizzle, Vitest, ESLint) and exposes scripts (`dev`, `build`, `db:push`, `test`) consumed by every child; `docker-compose.yml` provisions the full approved stack (PostgreSQL, Redis, MinIO, Orthanc, Keycloak, HAPI FHIR, Dicoogle, n8n, OHIF, LangGraph) so the frontend app routes API calls to the FastAPI backend while the backend agents persist state to the same DB and publish events via Redis; `drizzle.config.json` plus the `database_schema` child define the single source of truth for all domain tables referenced by both frontend server actions and backend endpoints; `.env.example` centralises every service URL and credential that children read at runtime. The `services_runtime` child boots in-memory mocks of these external services for local development, letting the frontend and tests run without the full compose stack.
