Run `bash services/start-all.sh` from the `services/` directory to start all services in-process, or `bash scripts/start-services.sh` when the pre-built Node server bundles exist under `/tmp/*-server/server.mjs`. Both require system binaries `redis-server`, `Orthanc`, `minio`, and `mc` (MinIO client) installed on PATH; LangGraph additionally requires a running PostgreSQL instance at `postgres:postgres@127.0.0.1:5432/app_db`.
