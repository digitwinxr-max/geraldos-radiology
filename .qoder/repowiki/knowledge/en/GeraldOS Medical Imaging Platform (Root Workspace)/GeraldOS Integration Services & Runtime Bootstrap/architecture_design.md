Two complementary entry points orchestrate the same set of integration services: `services/start-all.sh` starts each service from the `services/` directory (using local `.mjs` mock servers and the bundled `orthanc.json`), while `scripts/start-services.sh` does the same but expects pre-baked server bundles under `/tmp/*-server/server.mjs`. Each service is guarded by an idempotent health-check loop (`check_port` or `curl`) so repeated invocations are safe. The runtime includes both real binaries (Redis, Orthanc, MinIO) and lightweight Node.js HTTP servers that implement minimal OpenID Connect (Keycloak), FHIR R4, DICOM search (Dicoogle), automation API (n8n), and viewer proxy (OHIF). LangGraph is started as a Python Uvicorn app backed by Redis and PostgreSQL, with a hand-written multi-agent graph in `langgraph_agent.py` that routes incoming messages to one of six domain agents (executive, reception, scheduling, equipment, inventory, workflow) via a `StateGraph` conditional edge. Dependency direction is strictly outward: scripts depend on the `.mjs`/Python service implementations; there is no cross-service code coupling beyond shared localhost ports and environment variables.
