- Every table uses a `uuid` primary key generated by `DEFAULT gen_random_uuid()` except for append-only log tables (`audit_log`, `event_log`) which use `serial` auto-increment IDs.
- All tables include `created_at` timestamp defaulting to `now()`, and most also include an `updated_at` timestamp updated on modification.
- Free-form or structured JSON data is stored in `jsonb` columns with a default empty array literal `'[]'::jsonb` where applicable (e.g., bounding_box, suggested_differential, tags, permissions).
- Enumerated state fields (status, priority, modality, type) are modeled as `varchar` columns with explicit `DEFAULT` values rather than enum types.
- Referential integrity is enforced via explicit `ALTER TABLE ... ADD CONSTRAINT ... FOREIGN KEY` statements grouped after all `CREATE TABLE` blocks, using `ON DELETE NO ACTION ON UPDATE NO ACTION`.
- Business-identifying columns (mrn, claim_number, invoice_number, employee_number, accession_number, code) are declared `UNIQUE` via named constraints.
